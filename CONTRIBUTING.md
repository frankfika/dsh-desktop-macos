# Contributing

Thanks for helping improve DSH Desktop.

1. Open an issue for substantial behavior or UI changes before implementation.
2. Fork the repository and create a focused branch.
3. Run `./build.sh` and verify that the app launches on macOS 13 or newer.
4. Do not commit credentials, local DSH state, `.build`, ZIP, or DMG files.
5. Submit a pull request describing the user-visible change and verification performed.

Keep the launcher small and native. DeepSeek Harness runtime changes belong in the
[upstream repository](https://github.com/deepseek-ai/deepseek-harness).
